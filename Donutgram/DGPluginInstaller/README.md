# static plugin preview

`DGPluginInstaller.preview(data:fileName:)` bounds and validates immutable attachment bytes without creating a javascript runtime. ordinary `.js` documents are rejected. a single-file plugin uses a marker followed by `const manifest =` and a strict json object literal, both terminated by semicolons. object keys and strings use double quotes. expressions, comments inside metadata, duplicate keys and prototype-related keys are rejected. executable code after metadata is not evaluated.

packages use zip store or raw deflate, at most 8 mib compressed, 4 mib expanded, 128 entries, 1 mib per file, 8 path components and 240 ascii bytes per path. these limits match the runtime snapshot. package paths use letters, numbers, slash, dash, underscore and dot; locale contents support unicode. local and central headers, byte ranges, sizes, crc and file types must agree. encrypted files, streaming descriptors, multi-disk, zip64, unix link metadata, links, nested archives and unsupported resources are rejected. no operating-system archive extractor or filesystem writes are used. source modules are utf-8. preview copies incoming bytes into owned storage before validation so mutable external buffers cannot change the reviewed package.

optional icons are local assets only. imageio preflights a single png/jpeg/webp image, at most 1 mib and 2048 by 2048 pixels, then renders a bounded 256 pixel png with no source metadata. invalid images yield `iconData == nil`. rendering code must use this sanitized data rather than decode arbitrary resources again.

unsigned files have publisher `unverified` and trust `authorUnverified`. a signature is optional `signature.json` with exactly `algorithm: "Ed25519"`, a base64 32-byte `publicKey` and base64 64-byte `signature`. signing bytes start with utf-8 `donutgram.plugin.signature.v1\n`. for every file except signature.json, in ascending path order, append `pathUtf8Length:path:lowercaseSha256\n`. manifest.json is hashed after strict parsing and encoding with Foundation JSONEncoder sortedKeys and withoutEscapingSlashes. other files are hashed byte-for-byte. numeric canonicalization follows this encoder; authors should use integers and avoid numeric settings defaults needing cross-language float canonicalization. an independently supplied key attests content identity, not trusted publisher status or code safety. invalid signatures reject the package. no automatic trusted-key lookup, network revocation or automatic update exists here.

installation code must keep the verified value and reuse its bytes/digest after consent. reloading stored packages must call preview again and compare the persisted digest; copying metadata alone is not verification. unsigned replacements require explicit review even when ids match. these pure preview APIs do not install, grant permission or execute code.

`DGPluginInstallerTests` exercises static parsing, forbidden permissions, profile separation, versions, archive path attacks, crc corruption, icon fallback, signature tampering and limits. windows syntax parsing does not replace a swift build or these apple-host tests.
